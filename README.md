# dntr-photos

Serving layer for [Digital Nomad Trip Reports](https://www.digitalnomadtripreports.com/) campaigns.

This repository is public for one reason: beehiiv has no image upload API, so it can
only pull campaign images from a publicly fetchable URL. Everything here is destined
for a public newsletter within days anyway.

Contents, written automatically by the `dntr-prepare` workflow in `c3rra/dntr-alerts`:

```
<submission-id>/data.json     cost-of-living figures + ordered image URLs
<submission-id>/photo-1.jpg   submitter photos, HEIC converted to JPEG
```

Nothing is edited here by hand. Contributor photos are published with the
submitter's consent, given when they submit a trip report.
